## 维护约定

**自动生成的页面**（文件头有「请勿手工编辑」提示，改动会被覆盖）：

```powershell
# 刷新接口清单（02）——数据来自 src/main/resources/docking-api-catalog.json
node tools/build-kb.mjs

# 刷新数据字典（05）——数据来自源文档《数据字典.md》
node tools/extract-dictionary.mjs

# 重新生成后，浏览器页面会自动反映（若应用在运行，需重启或重新打包）
```

**接口定义变更流程**：源文档更新 → `node tools/build-catalog.mjs` 更新接口清单 JSON →
`node tools/build-kb.mjs` 刷新知识库页面 → 提交。

```text
Apifox 分享文档（源，需密码）
    └─ 交接资料包 E:\ai-work\docs\2026-09-23-city-lifeline-api-docs
         ├─ 接口梳理.md / 接口字段明细.md / 数据字典.md   ← 原始素材
```

知识库**不复制**源文档的全部内容，只保留对接时真正要查的部分，并补充代码侧的实现约定。
需要完整原文时请回查交接资料包。
